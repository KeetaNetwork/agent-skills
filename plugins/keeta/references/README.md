# Keeta reference notes

These notes are short mirrors of public Keeta pages the skills cite. Each file names the canonical URL and the method shapes agents are allowed to call. The live page remains the source of truth.

`scripts/sync-keeta-docs.mjs` fetches those URLs and checks that the method names in this folder are still present. It does not vendor the full pages.
