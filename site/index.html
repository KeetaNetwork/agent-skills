How it works

One market for spare inference.

A scheduler matches each request to an online provider that has the model and fits the price. Every payment settles on the Keeta ledger, and every balance is read from it.

Provide

Sell spare capacity

Run the macOS app or the Linux CLI, pick the models that fit, set a price per million tokens, and get paid for each request.

Buy locally

Inference for your agents

The same app or CLI gives agents on your machine a local OpenAI-compatible endpoint, with spend limits you set.

Public API

One endpoint for everyone else

Servers and other platforms call api.keeta.ai with the OpenAI chat API and pay per request with x402.

Payments

Pay with Keeta stablecoins

Buy Keeta Compute Credits with KUSD or another Keeta stablecoin. Each request escrows its most possible cost on the ledger; the provider is paid what it billed, less a 0.25% network fee, and the rest comes back.

Receipts

Signed for every job

Each response carries the provider's signed receipt: model, weights hash, runtime, tokens, price and amount.

Privacy

Your machines, your rules

Providers can see the prompts they serve, so sensitive work can stay on your own machines or a list of buyers you trust.
